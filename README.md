# KemalG-u

## Türkçe

Araştırma notları, yazılım örnekleri ve yerel prototiplerden seçilmiş çalışmalar. Bunlar bitmiş ürün, üretim güvenliği veya ölçülmüş gerçek dünya performansı iddiası taşımaz. Kapsam, testler ve hak sınırları için ilgili deponun README'sine bakın.

- [Jev teknik araştırması](https://github.com/KemalG-u/jev-teknik-arastirma) — karar arayüzü ve değerlendirme sınırları üzerine bağımsız, kaynaklı araştırma; ürün veya üretim benchmark'ı değil. Yeniden kullanım lisansı seçilmedi.
- [Jev demo](https://github.com/KemalG-u/jev-demo) — sabit örnek kurallarla çalışan arayüz ve demo kaynak adayı; gerçek Jev modeli veya sağlayıcı çalıştırmaz. Yeniden kullanım lisansı verilmedi; hak incelemesi sürüyor.
- [Model Laboratuvarı](https://github.com/KemalG-u/model-laboratuvari) — veri şeması ve konuşmacı ayrımı denetimi adayı; testleri sentetik, model eğitimi veya gerçek ses işleme değil.
- [Proje Pusulası](https://github.com/KemalG-u/proje-pusulasi) — proje, karar ve risk notları için sentetik örnek içeren yerel HTML/JavaScript panosu. Gerçek ajan entegrasyonu yok; üçüncü taraf hak zinciri henüz doğrulanmadı.
- [KarıncaAI İçerik Stüdyosu](https://github.com/KemalG-u/karincaai-icerik-studyosu) — çevrimdışı, dar bir kod seçkisi; tam stüdyo, model sağlayıcısı veya sosyal medyaya gönderim aracı değil. Hak sınırları depo belgelerinde açıklanıyor.
- [AjanMühendis kaynak adayı](https://github.com/KemalG-u/ajanmuhendis) — MühendisAl öğrenme sitesinden seçilmiş arka uç, stil ve JavaScript; hedef ajan stüdyosu değil. Gerçek tarayıcı akışı ve tüm haklar doğrulanmadı.
- [KarıncaAI algoritma örnekleri](https://github.com/KemalG-u/karincaai-algoritma-ornekleri) — bağımsız C# algoritma örnekleri; gerçek dikte uygulaması değil. Gerçek ses, VAD/ASR ve ürün entegrasyonu test edilmedi.

## English

A selection of research notes, software samples and local prototypes. These are not claims of finished products, production security or measured real-world performance. See each repository's README for its scope, tests and rights limitations.

- [Jev technical research](https://github.com/KemalG-u/jev-teknik-arastirma) — independent, sourced research into the decision interface and evaluation limits; not a product or production benchmark. No reuse license has been selected.
- [Jev demo](https://github.com/KemalG-u/jev-demo) — a UI and demo source candidate using fixed example rules, not an actual Jev model or provider. No reuse license has been granted; rights review remains open.
- [Model Laboratory](https://github.com/KemalG-u/model-laboratuvari) — a data schema and speaker-split checking candidate with synthetic tests, not model training or real audio processing.
- [Project Compass](https://github.com/KemalG-u/proje-pusulasi) — a local HTML/JavaScript dashboard for project, decision and risk notes, with a synthetic example. No real agent integration; third-party provenance remains unverified.
- [KarıncaAI Content Studio](https://github.com/KemalG-u/karincaai-icerik-studyosu) — a narrow offline code selection, not the full studio, a model provider or a social-posting tool. See the repository's rights limitations.
- [AjanMühendis source candidate](https://github.com/KemalG-u/ajanmuhendis) — selected backend, styling and JavaScript from the MühendisAl learning site, not the intended agent studio. The actual browser flow and full rights chain remain unverified.
- [KarıncaAI algorithm samples](https://github.com/KemalG-u/karincaai-algoritma-ornekleri) — standalone C# algorithm examples, not a real dictation application. Real audio, VAD/ASR and product integration have not been tested.
